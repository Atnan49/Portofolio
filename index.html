FAQ

PERTANYAAN UMUM

Pertanyaan yang sering diajukan mengenai kerja sama pembuatan website dan sistem.

Siapa yang mengerjakan website saya?
Seluruh proses rancangan dan penulisan kode dikerjakan langsung secara personal oleh saya (Atnan) dengan standar kode bersih dan efisien.
Berapa lama waktu pengerjaan website?
Paket Pelajar / Landing Page membutuhkan waktu sekitar 3 sampai 5 hari kerja. Paket Pro Business sekitar 7 sampai 10 hari kerja, dan aplikasi web kustom sekitar 14 sampai 30 hari kerja tergantung jumlah fitur.
Apakah saya mendapatkan source code dan akses penuh?
Ya, Anda mendapatkan akses penuh ke domain, akun hosting, serta repository source code GitHub untuk proyek yang dikerjakan.
Teknologi apa saja yang digunakan?
Stack utama saya mencakup Next.js (React untuk web modern SSR), Laravel (PHP untuk backend dan database kompleks), serta Vanilla Web (HTML/CSS/JS) untuk landing page ringan berkecepatan tinggi.
Bagaimana mekanisme pembayaran?
Sistem pembayaran bertahap: uang muka (DP) 50% saat proyek disepakati dan pengerjaan dimulai, lalu pelunasan 50% setelah website selesai diuji coba dan siap diluncurkan.
Apakah melayani integrasi kustom?
Ya, saya melayani integrasi REST API, bot WhatsApp, sistem kasir POS, payment gateway, hingga dashboard spreadsheet khusus. Silakan hubungi saya untuk diskusi teknis.
