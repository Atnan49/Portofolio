SakuPOS — Enterprise Offline POS & Inventory Management

Solusi sistem kasir dan manajemen stok modern khusus UMKM & Retail. Dirancang dengan arsitektur Offline-First — memungkinkan transaksi kasir, scan barcode, dan cetak struk thermal berjalan 100% tanpa jaringan internet, lalu tersinkronisasi otomatis ke Cloud saat sinyal kembali aktif.

// Kemampuan Utama Sistem

Fitur Kasir & Stok Berstandar Enterprise.

signal_wifi_off

Zero Downtime Sales

Transaksi kasir dapat memproses pemesanan, diskon, dan PPN tanpa tergantung jaringan seluler atau Wi-Fi. Semua data tersimpan aman di basis data browser (IndexedDB via Dexie.js).

qr_code_scanner

Camera & Hardware Barcode

Integrasi library html5-qrcode memungkinkan pencarian produk instan menggunakan kamera smartphone maupun scanner barcode USB/Bluetooth fisik.

receipt_long

Cetak Struk Thermal Native

Mendukung pencetakan struk transaksi langsung ke printer thermal POS dengan tata letak yang bersih, header toko dapat dikustomisasi, dan rincian pembayaran.

cloud_sync

Auto Cloud Backup (Supabase)

Saat perangkat kembali terhubung ke internet, sistem mendeteksi sinyal secara otomatis dan melakukan enkripsi serta sinkronisasi data transaksi ke database Supabase.

inventory_2

Smart Stock Alert & Logs

Pelacakan kuantitas barang secara *real-time* saat terjadi checkout, notifikasi batas stok minimum (*low stock warning*), dan audit log pergerakan stok.

analytics

Executive Sales Analytics

Dashboard bisnis yang menampilkan grafik omzet bulanan, produk terlaris (*best seller ranking*), analisis tren jam sibuk toko, dan ekspor laporan ke Excel (XLSX).

// Spesifikasi Arsitektur Rekayasa Web

Arsitektur & Komponen Teknis.

01 / FRONTEND CORE

React 19 & TypeScript

Dibangun di atas React versi 19 terbaru dengan ketikan ketat TypeScript untuk performa tinggi, modularitas komponen, dan bebas dari runtime error.

02 / LOCAL DATABASE

Dexie.js (IndexedDB Wrapper)

Menyimpan seluruh katalog produk, histori kasir, dan penyesuaian stok di dalam IndexedDB browser lokal menggunakan dexie-react-hooks.

03 / CLOUD BACKEND

Supabase Cloud Integration

Menyediakan otentikasi pengguna, penyimpanan data cloud terenkripsi, dan pipeline sinkronisasi otomatis saat terhubung ke internet.
